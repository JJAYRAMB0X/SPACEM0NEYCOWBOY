Getting Started
1
Open the Wallet Manager and add your EVM and/or Solana addresses
2
Hit Scan All Wallets to auto-discover holdings across every EVM chain + Solana in one click
3
Use the search bar or + Manual to add stocks, metals, cash, or anything off-chain
4
Right-click any asset to edit it, assign categories, or add notes
🔍 Search Tips
₿ Crypto
  • Search by symbol — BTC, ETH, SOL
  • Search by name — Bitcoin, Monero
  • Paste a contract address for exact lookup
  • Results from DexScreener & CoinGecko
  • If a result doesn't add on first click, try clicking it again
📈 Stocks
  • Company name works best — "Air Canada"
  • Ticker also works — AAPL, MSFT, AC
  • US stocks via Finnhub
  • Canadian & international via Twelve Data
  • If one result fails, try a different one
  • If a result doesn't add on first click, try clicking it again
👛 Wallet Scanning
  • Open the Wallet Manager to add EVM and Solana addresses
  • Scan All Wallets — one-click discovery across every EVM chain + Solana
  • Or use the scan button on an individual wallet to scan just that one
  • Results: green = new tokens, gray = already tracked, red = balance mismatch
  • Right-click a token → Pull Balance to refresh on-chain balance from saved wallets
  • Chain matters — set the correct chain on a token for wallet balance lookups to work
✏️ Manual Entry & Updates
  • Use + Manual if search doesn't find what you need
  • Add Crypto, Stocks, Precious Metals, or Cash manually
  • Right-click any asset → Edit Info to update price or set a per-token auto-update interval (green text = auto-refreshing)
